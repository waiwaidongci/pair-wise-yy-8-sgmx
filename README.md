# 晾晒排位与打包放行台

纸坊晾晒场换班用：批次入晒占位、两次复称放行、打包收帘。

## 运行

```bash
npm start
```

访问 `http://localhost:3039`。数据保存在 `data/paper-drying-release.json`。

## 规则

- 每批登记入晒重量、竹帘位、翻帘人和开始时刻；未收帘的竹帘位不能再排下一批。
- 列表可筛选「晾晒中 / 待复称 / 可打包」，顶部显示空竹帘位数量与竹帘位看板。
- 晾晒结束后连续两次称重，含水率均低于 12%（一成二）且两次相隔满 6 小时，才放行打包。
- 入晒重量更正或竹帘挪位会让原放行失效：旧称重结果保留在批次履历（标记为旧轮次作废），需重新复称。
- 打包收帘后竹帘位才释放为空位。
