# 晾晒排位与打包放行台

竹纸作坊晾晒场管理：入晒登记、竹帘位防重排、双称达标放行、重量更正与竹帘挪位留痕。

运行：

```bash
npm start
```

访问 `http://localhost:3039`。数据保存在 `data/paper-drying-slots.json`（首次启动自动播种示例数据）。

## 规则

- **入晒登记**：每批记录入晒重量、竹帘位（东1~东10、西1~西10，共 20 位）、翻帘人、开始时刻。
- **帘位互斥**：未收帘的竹帘位不能再排下一批；挪位只能选空位，收帘后帘位立即腾空。
- **打包放行**：连续两次称重含水率均低于一成二（12%）且两次相隔满六小时才放行；任一条件不满足显示"待复称"。
- **放行失效**：入晒重量或某次称重重量更正、竹帘挪位，都会使原放行作废，旧放行与旧结果保留在批次履历中，需重新连续两次合格称重。
- **打包收帘**：只有"可打包"批次可收帘。
- **列表**：可按 晾晒中 / 待复称 / 可打包 / 已收帘 筛选，统计区显示各状态数量与空竹帘位数。
